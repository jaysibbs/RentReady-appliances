Warranty and returns

The warranty and return route is part of the approval decision.

Because RentalReady may source new, graded, or refurbished stock, the warranty and return position can vary by supplier, appliance type, and condition route. The quote should make that clear before a customer approves spend.

  • New or graded appliances may carry supplier or manufacturer warranty depending on the product, seller, and source.
  • Refurbished appliances are quoted by condition tier. Any warranty, return window, or limitation should be confirmed before order approval.
  • The quote should separate appliance cost, condition route, visible cosmetic notes, warranty or return position, and logistics assumptions where relevant.
  • Customers should report a suspected fault as soon as possible with photos, product details, access notes, and a description of the issue.
  • Incorrect measurements, blocked access, unsuitable connections, missing specialist trades, or gas/electrical installation issues may affect returns or extra costs.
