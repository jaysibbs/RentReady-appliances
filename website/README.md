# RentalReady Public Website

Customer-facing RentalReady Appliances pages, public assets, brand files, and website styling live here.

Cloudflare project:

- Project: `rentalreadyappliances`
- Build command: `node scripts/build_site.mjs`
- Output directory: `dist`
- Domain: `rentalreadyappliances.com`

The website should stay stable and lead-focused. It can send future enquiry data into the sourcing agent, but procurement matching and bid-pack logic should not live in this folder.
